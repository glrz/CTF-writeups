# Brixel CTF Winter Edition 2020

This competition allowed up to 5 members to participate but I participated solo in this competition as `T34M1`through CTFtime platform. The event details can be found [here](https://ctftime.org/event/1194).

I participated with my initials `glrz` and managed to solve 36 challenges in the competition. I would say this CTF competition was beginner-friendly and it helped me to pick up new knowledge and concepts in Cybersecurity.

For this writeup, I will not be doing a full writeup for all 36 challenges. I will only include those I find interesting or beneficial in adding to my knowledge.
