## Linux Command

![](<../../.gitbook/assets/image (721).png>)

In this challenge, we had to netcat into the `ip address` provided and solve 2 stages of challenges.

Stage 1 : Make a `chall1` directory and allow access.&#x20;

For stage 1, we use the `mkdir` command to create a new directory

Stage 2 : Copy or move `file1` to the `chall1` directory.

For stage 2, we use `cp` command to copy the file to `chall1` directory.

After we completed the tasks, we use `cd` to change directory to the `chall1` directory, and we would get the string `Simple_play_linux_command`

![](<../../.gitbook/assets/image (722).png>)

Finally, we generate the MD5 of `Simple_play_linux_command` using an online [MD5 Hash Generator](https://www.md5hashgenerator.com/).
