### The Priceless Maracus

I did not save the challenge description for this challenge since I did not solve it during the training itself. I solved it after the training.&#x20;

The reason why I did not solve it during the training was because the environment that I had to use did not include the right tools such as Audacity to solve it. Transferring the file to my local machine was also quite cumbersome, hence I did not attempt it.

First, we can navigate to the challenge directory. There is a `wav` file and `zip` file.

```bash
root@ip-172-31-24-9:/home/ubuntu# cd ThePricelessMaracas/
root@ip-172-31-24-9:/home/ubuntu/ThePricelessMaracas# ls
'Kakariko Village.wav'   maracas.zip
```

For easier identification and file transfer sake, I'll rename this audio file.

```bash
root@ip-172-31-24-9:/home/ubuntu/ThePricelessMaracas# mv Kakariko\ Village.wav key.wav
```

Next, I transferred the file using `scp` to local machine so that I can use Audacity:

```bash
C:\Users\Gadiel\Downloads>scp -i AYCEP.pem ubuntu@ec2-54-179-147-9.ap-southeast-1.compute.amazonaws.com:/home/ubuntu/ThePricelessMaracas/key.wav .
key.wav                                                                                            100%   30MB   3.6MB/s   00:08
```

In Audacity Spectrogram view, we will be able to see `Morse Code` at the bottom. It is much clearer when zoomed in.

<figure><img src="../../.gitbook/assets/image (127).png" alt=""><figcaption></figcaption></figure>

We can use [CyberChef](https://cyberchef.org/#recipe=From\_Morse\_Code\('Space','Line%20feed'\)\&input=LS4tLSAtLS0gLi4tIC4tLiAtLi0gLiAtLi0tIC4uIC4uLiAtLS0uLi4gLi4uLiAuIC4uLiAtIC4uLQ) to decode this and we will get the key which is the password to unlock the zip file.

<figure><img src="../../.gitbook/assets/image (18) (4).png" alt=""><figcaption><p>YOURKEYIS:HESTU</p></figcaption></figure>

Note that the password is typed in lower case

```bash
root@ip-172-31-24-9:/home/ubuntu/ThePricelessMaracas# unzip maracas.zip
Archive:  maracas.zip
[maracas.zip] maracas.txt password:
  inflating: maracas.txt
```

Finally, we can read the contents of the extracted `txt` file which contained the flag.

```bash
root@ip-172-31-24-9:/home/ubuntu/ThePricelessMaracas# cat maracas.txt

Shala-kala! Those are my maracas! Please giivveeee them to meeeee!!
\(^_^)/ Da-na-na-naaaa!

Your flag is here:
br3@th0f+h3W!ld

Thank you, shalakala! <3
```

Flag: br3@th0f+h3W!ld
